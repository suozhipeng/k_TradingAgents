# TASKS

## 目标
把当前 TradingAgents 从“通用多 Agent 金融研究/交易建议框架”二次开发成：

**A 股辅助看盘系统**

强调：
- 辅助看盘
- 盘前/盘中/盘后观察
- 风险提示与题材跟踪
- 不直接做真实交易执行

## 拆解原则
- 保留现有 LangGraph 多 Agent 骨架
- 弱化“直接给交易评级”的倾向
- 强化 A 股场景特有数据、题材、资金、公告、监管、情绪
- 输出从“下单建议”转向“看盘结论 + 观察清单 + 风险提示”

---

## Phase 0：边界定义与需求确认

### 任务 0.1：明确产品定位
- 定义系统是：盘前助手 / 盘中监控 / 盘后复盘 / 全流程
- 定义目标用户：个人投资者 / 研究员 / 自媒体 / 量化研究辅助
- 定义输出边界：是否允许出现 Buy/Sell 词汇
- 定义是否只做沪深 A 股，是否含 ETF、可转债、港股通、北交所

### 任务 0.2：明确合规与风险提示
- 设计固定免责声明
- 明确“辅助看盘，不构成投资建议”输出规范
- 审核是否需要保留原 `PortfolioRating` 五档评级；大概率建议改为观察类标签

### 任务 0.3：定义运行模式
- 单次分析
- 定时巡检
- 热点板块扫描
- 自选股批量看盘
- 异动预警

> 若面向真实用户上线，合规要求与展示限制 **需人工确认**。

## Phase 1：A 股领域模型重构

### 任务 1.1：重新定义 agent 角色
建议从当前角色演化为：
- 市场结构分析师（指数/情绪/量能/北向）
- 板块题材分析师（概念、行业、龙头、联动）
- 公告/新闻分析师（公告、监管函、业绩预告、政策）
- 资金流分析师（主力、北向、融资融券、大单）
- 技术形态分析师（日线/分时/均线/量价）
- 风险提示官（停牌、异动、减持、业绩雷、监管风险）
- 盘面总结经理（汇总看盘结论）

### 任务 1.2：调整状态模型 `AgentState`
新增候选字段：
- `sector_report`
- `capital_flow_report`
- `announcement_report`
- `market_breadth_report`
- `watchlist_actions`
- `risk_flags`
- `session_type`（pre_market / intraday / post_market）

### 任务 1.3：重定义最终输出 schema
将当前：
- `ResearchPlan`
- `TraderProposal`
- `PortfolioDecision`

改造成更适合看盘的结构：
- `WatchlistDecision`
- `MarketSummary`
- `RiskAlert`
- `SectorRotationSummary`

输出建议包含：
- 今日关注标的
- 关注原因
- 关键价位
- 风险点
- 观察动作（不是交易动作）

分析内容：
- 主力净流入/净流出
- 北向资金

### 任务 3.5：技术形态分析师

## Phase 4：图编排改造

### 任务 4.1：替换现有美股导向流程
当前链路：
`Analysts -> Bull/Bear -> Research Manager -> Trader -> Risk Debate -> Portfolio Manager`

A 股看盘建议链路可改成：
`市场/题材/公告/资金/技术/风险 -> 盘面总结经理 -> 观察清单生成器`

### 任务 4.2：移除或弱化 Trader 节点
- 不再强调下单动作
- 改为“观察动作建议”
  - 关注回踩
  - 观察放量突破
  - 等待公告落地
  - 规避追高

### 任务 4.3：重写条件逻辑
- 不再围绕 bull/bear 回合数设计
- 改为：
  - 必跑节点
  - 条件节点（仅盘中运行）
  - 风险触发节点（命中条件才运行）

### 任务 4.4：支持批量 watchlist 模式
- 输入一组自选股
- 对每只股票跑轻量版流程
- 最终输出 watchlist dashboard / markdown 摘要

## 最小可行版本（MVP）建议

### MVP-1：A 股单标的盘后分析
- 接入 1 个稳定 A 股行情源
- 接入 1 个公告/新闻源
- 保留 3~4 个 analyst
- 输出中文 markdown 报告

### MVP-2：A 股自选池批量看盘
- 支持一组股票
- 每只股票输出短摘要
- 汇总成 watchlist 总表

### MVP-3：盘前/盘后自动简报
- 定时运行
- 输出到 Markdown / 飞书 / Telegram

## 关键结论
把本项目改造成 A 股辅助看盘系统，最适合的思路不是：
- 在现有美股交易建议流程上打补丁

而是：
- **复用其多 Agent 图编排框架**
- **重做数据层、角色层、输出层**
- **把“交易建议系统”转成“看盘辅助系统”**

这是一次中等到较大规模的产品级改造，不是简单换源。
